Live quizzes you actually own.

QuizDock is an open-source, self-hosted live quiz platform with bright, projector-ready screens. Players join by PIN or QR with no account, and your data never leaves your servers.

Everything for a live game, on your infra

Five things QuizDock does well. The complete list is further down.

⚡

Live, in real time

Players join by 6-digit PIN or QR code from any device, no account, and get a generated avatar. A Socket.IO engine with authoritative server timing keeps everyone in step — a handful or a few hundred.

🖥️

Made for the big screen

Bright, high-contrast projection screens, with separate projection and control windows. Pace by hand or automatically, look back over any played question, survive a server restart.

🧩

A real quiz builder

Seven question types — single / multiple choice, true-false, text, numeric, ordering, poll — with images, Markdown everywhere, content slides between questions, backgrounds and answer explanations — and, experimental, video & sound.

🏆

Scoring that rewards speed

Time-weighted points, streak bonuses, leaderboard between questions, final podium. Per question: closest answer wins, partial credit, typo-tolerant text, double or fixed points.

🏠

Self-hosted and private

One Docker image (amd64 / arm64), no SaaS, no tracking, no ads. Five interface languages, rebrand name, logo and CSS without a rebuild. The questions, the answers and the results stay on your servers.

How it works

  1. 1

    Host creates a session

    Build a quiz, hit present — the console shows a PIN, a QR code and the address participants will reach.

  2. 2

    Players join by PIN or QR

    No account, no install. They pick a nickname and they are in the lobby instantly.

  3. 3

    Play, score, review

    Answer in real time, look back at any question, crown the podium, then explore results and export to CSV.

Two ways to run it

Same image, one switch: AUTH_MODE decides who can host. Players never sign in, in either mode.

Default

Local mode

A classroom, a meeting room, a trusted network.

  • Zero configuration — start the container and play.
  • One host seat: a host signs in with just a name and takes it, releases it when done.
  • Two sample quizzes included to present right away.
For an organisation

OIDC mode

Hosts sign in through your identity provider.

  • Any OpenID Connect provider: Keycloak, Authentik, Entra ID, Google…
  • As many hosts as you like, each with their own quizzes.
  • The host role is granted from the IdP.

Everything else

The complete list — what you get once a session runs.

  • Rich text — prompts, options and descriptions in Markdown with a visual editor: bold, lists, code, inline images.
  • Content slides — headings, text, images, 2–3 columns between questions; image or gradient backgrounds, faithful 16:9 preview.
  • Answer explanations — shown at the reveal, with a per-question reveal delay in automatic mode.
  • Player avatars — a unique generated Multiavatar for every player, no upload, the same face on every screen.
  • Host in control — Console / Projection / Participant views, layout edits reach a running session at its next step, sessions survive a restart.
  • Video & sound experimental — MP4 videos and MP3 sounds in questions, loudness-matched, drawn as a waveform with a playhead that follows the projection; started on the same instant on every device, fetched ahead from the lobby, and the room waits a moment for a device still loading; listen first questions open the answers once the media has played. Tested in Chromium browsers, not yet on iPhone.
  • Remote participants experimental — someone following from home says so when joining and gets the whole question on their device; who hears the sound is set per quiz, per question and per session.
  • Invitation address — the QR code and join link point where phones can actually reach the instance: public URL, LAN IP or any address.
  • Player feedback — stars and an optional comment at the end; hosts see the distribution and browse the reviews. Off per quiz when unwanted.
  • Answer capture — optionally keep every player’s individual answers for audit, certification or follow-up, decided per session.
  • History & exploration — archived sessions with per-question success rates, average times and per-player answer sheets.
  • CSV export — overall results and per-player answer sheets.
  • Quiz import / export — a quiz travels as a portable bundle (quiz.json + media, zipped): back it up, move it, share it — from the app or the CLI.
  • Multilingual — English, French, Spanish, Simplified and Traditional Chinese, one language per instance.
  • White-label — name, logo and CSS via an env variable and a mounted folder, no rebuild.
  • Operator script — quizdock init / up / backup / upgrade / doctor: guided setup and day-to-day admin, Docker only.
  • Hardened runtime — distroless image, non-root, read-only root FS, capabilities dropped; dependencies and image scanned on every push.
  • MIT licensed — free to use, modify and redistribute, including for internal self-hosting.

Run it in one command

App and database in a single container — nothing else to install. Data persists in the quizdock volume.

docker run -p 18080:3000 -v quizdock:/data fchaussin/quizdock:standalone

# then open http://localhost:18080
