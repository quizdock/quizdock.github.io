Live quizzes you actually own.

QuizDock is an open-source, self-hosted live quiz platform with bright, projector-ready screens. Players join by PIN or QR with no account, and your data never leaves your servers.

Everything for a live game, on your infra

From the quiz builder to the projector, the leaderboard and the data export.

⚡

Real-time multiplayer

Socket.IO game engine with authoritative server timing. Players join a session by 6-digit PIN or QR code — from a handful to a few hundred.

🦄

Player avatars

Every player gets a unique, generated Multiavatar avatar — no upload, no account, and the same face on every screen.

🖥️

Projector-ready

Bright, high-contrast screens built for the big screen, sized in one typographic base so they scale from a phone to a projector. Console, projection and participant views on one session.

🧩

Quiz builder

Seven question types, up to 8 answers with colour/shape pairs, image & audio media, Markdown with a visual editor, content slides with backgrounds, drag-and-drop ordering.

🎯

Scoring rules

Time-weighted points and streaks — plus, per question: closest answer wins, partial credit, typo-tolerant text, double or fixed points.

🎛️

Host in control

Look back over played questions without replaying anything, pause, pace by hand or automatically, edit layouts while a session runs, survive a server restart.

📡

Invitation address

The QR code and join link point where phones can actually reach the instance — public URL, LAN IP or any address, picked from the console.

⭐

Player feedback

Players rate the quiz with stars and an optional comment at the end; hosts browse the reviews. Off per quiz when unwanted.

💾

Answer capture

Optionally keep every player’s individual answers for audit, certification or follow-up — decided knowingly, per session.

🔎

History & exploration

Archived sessions with per-question success rates, average times and per-player answer sheets; CSV export of everything.

📦

Import / export

A quiz travels as a portable bundle (quiz.json + media, zipped): back it up, move it, share it.

🌍

Multilingual

English, French, Spanish, Simplified and Traditional Chinese — one language per instance.

🏠

Self-hosted & private

Your infra, one Docker image, no SaaS, no tracking. Players need no account; hosts can plug in any OpenID Connect provider.

🎨

White-label

Rebrand the name, logo and CSS with an env variable and a mounted folder — no rebuild.

Self-host in 2 minutes

Easiest — one container (app + database bundled), ideal on Docker Desktop: 

docker run -p 18080:3000 -v quizdock:/data fchaussin/quizdock:standalone

# then open the app in your browser
open http://localhost:18080

Or, for production, the fchaussin/quizdock app image with your own Postgres / Redis via compose: 

docker pull fchaussin/quizdock:latest
curl -O https://raw.githubusercontent.com/quizdock/quiz-dock/main/docker-compose.prod.yml
docker compose -f docker-compose.prod.yml up -d

# then open the app in your browser
open http://localhost:18080
View on Docker Hub ↗

Prefer building from source? git clone the repo and run the same compose with --build. Rebrand and pick a language without rebuilding via APP_NAME / APP_LANG and a mounted branding/ folder. Playing on a LAN? Set HOST_LAN_IPS (or type the address in the console) so the QR code points where phones can reach.

How it works

  1. 1

    Host creates a session

    Build a quiz, hit present — the console shows a PIN, a QR code and the address participants will reach.

  2. 2

    Players join by PIN or QR

    No account, no install. They pick a nickname and they are in the lobby instantly.

  3. 3

    Play, score, review

    Answer in real time, look back at any question, crown the podium, then explore results and export to CSV.
